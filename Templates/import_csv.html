รูปแบบไฟล์ที่ถูกต้อง

ไฟล์ CSV ของคุณต้องมี Header (แถวแรก) ที่มีชื่อตรงกับคอลัมน์ในฐานข้อมูล

คอลัมน์ที่จำเป็น:

  • name - ชื่อสินค้า
  • price - ราคาขาย (ตัวเลข)
  • stock - จำนวนสต็อก (ตัวเลข)

คอลัมน์ที่ไม่บังคับ:

  • cost - ต้นทุนสินค้า
  • sku - รหัส SKU (ต้องไม่ซ้ำกัน)
  • description - รายละเอียดสินค้า
  • category - หมวดหมู่
  • color - สี
  • size - ขนาด
